Dynamic Creative Optimization

One template. Eight ads.

Every banner below is the same 300x250 build. The headline, offer, paint color, call to action, and click-through URL all come from one row of a data feed, the way an ad server assembles a DCO ad at serve time.

  1. 1. FeedEight rows in feed.js, one per audience: six cities, a retargeting segment, and a conquest segment.
  2. 2. TemplateOne build on the machine.js framework and its builderTimeLine class. No row-specific code.
  3. 3. AdThe template reads its row, fits the copy, paints the car, and tags the click URL for reporting.
